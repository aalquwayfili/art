# Falcon's Hour

[![preview](preview.webp)](https://aalquwayfili.com/art/falcons-hour/)

A saker climbs until the whole sand sea is one grain on the globe, then stoops home to the glove.

Three-block woodcut in WebGL: gouge marks along the forms, misregistered inks, paper texture.

An `index.html`, the code in `main.js`, and the shaders in `block.frag`, `print.frag` and `quad.vert`; no libraries. [View it live](https://aalquwayfili.com/art/falcons-hour/). Add `?t=<seconds>` to render a single fixed frame.
