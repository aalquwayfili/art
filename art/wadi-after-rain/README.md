# Wadi After Rain

[![preview](preview.webp)](https://aalquwayfili.com/art/wadi-after-rain/)

A flash flood cuts new channels down a dry wadi, seen by a drone's thermal camera.

Shallow-water virtual-pipe model with erosion (Mei et al. 2007), in an ironbow false-colour palette.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/wadi-after-rain/). Add `?t=<seconds>` to render a single fixed frame.
