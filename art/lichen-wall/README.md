# Lichen Wall

[![preview](preview.webp)](https://aalquwayfili.com/art/lichen-wall/)

Lichen spreads along the cracks of an old stone wall while a snail grazes through it.

Gray–Scott reaction–diffusion guided by the cracks, painted in ink wash on washi.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/lichen-wall/). Add `?t=<seconds>` to render a single fixed frame.
