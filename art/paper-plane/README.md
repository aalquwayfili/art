# Paper Plane

[![preview](preview.webp)](https://aalquwayfili.com/art/paper-plane/)

Thrown from a rooftop at noon, it circles the whole city and comes home the next noon.

PS1-style 3D in WebGL: 240-line render, vertex snapping, 15-bit colour with a Bayer dither.

An `index.html`, the code in `main.js`, and the shaders in `common.glsl`, `post.frag`, `scene.frag`, `scene.vert`, `sky.frag` and `sky.vert`; no libraries. [View it live](https://aalquwayfili.com/art/paper-plane/). Add `?t=<seconds>` to render a single fixed frame.
