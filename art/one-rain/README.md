# One Rain

[![preview](preview.webp)](https://aalquwayfili.com/art/one-rain/)

It rained once this year. Everything underground had been waiting for it.

Pen and ink on paper: wobbling lines, engraved hatching, stippled soil that darkens as the water sinks in.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/one-rain/). Add `?t=<seconds>` to render a single fixed frame.
