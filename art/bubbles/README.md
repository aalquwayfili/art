# Bubbles over red rocks

[![preview](preview.webp)](https://aalquwayfili.com/art/bubbles/)

Glass bubbles over a red mesa and clouds.

Canvas 2D with layered blur and gradients.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/bubbles/). Add `?t=<seconds>` to render a single fixed frame.
