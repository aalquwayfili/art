# Neural Weather

[![preview](preview.webp)](https://aalquwayfili.com/art/neural-weather/)

A tiny neural network learns, drawn as a weather chart; as the loss falls, the storm clears.

A 2-16-16-1 MLP trained in plain JS with Adam; isobars are its output, fronts its decision boundary.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/neural-weather/). Add `?t=<seconds>` to render a single fixed frame.
