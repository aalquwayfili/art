# Seismic Wave

[![preview](preview.webp)](https://aalquwayfili.com/art/seismic-wave/)

A thumper truck shakes the desert; where the bang going down meets the echo coming up, the buried layers light up.

Finite-difference acoustic waves and reverse-time migration, drawn at 320×180 with dither.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/seismic-wave/). Add `?t=<seconds>` to render a single fixed frame.
