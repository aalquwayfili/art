# Save Point

[![preview](preview.webp)](https://aalquwayfili.com/art/save-point/)

A traveller rests on a bench in an old cistern while the lamp steadies, then leaves.

PS1-style 3D: vertex snapping, affine textures, fog, 15-bit colour with dither.

An `index.html`, the code in `main.js`, and the shaders in `post.frag`, `post.vert`, `scene.frag` and `scene.vert`; no libraries. [View it live](https://aalquwayfili.com/art/save-point/). Add `?t=<seconds>` to render a single fixed frame.
