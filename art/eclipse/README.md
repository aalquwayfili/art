# Eclipse over a desert of signals

[![preview](preview.webp)](https://aalquwayfili.com/art/eclipse/)

A dark sun with a turning star pattern over a desert of flowing contour lines.

One WebGL fragment shader: warped noise, girih star lines, film grain.

An `index.html`, the code in `main.js`, and the shaders in `shader.frag` and `shader.vert`; no libraries. [View it live](https://aalquwayfili.com/art/eclipse/). Add `?t=<seconds>` to render a single fixed frame.
