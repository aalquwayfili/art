# Grass and red sun

[![preview](preview.webp)](https://aalquwayfili.com/art/red-sun/)

Pampas grass backlit by a red sun.

Canvas 2D strokes with layered blur.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/red-sun/). Add `?t=<seconds>` to render a single fixed frame.
