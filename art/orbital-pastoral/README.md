# Orbital Pastoral

[![preview](preview.webp)](https://aalquwayfili.com/art/orbital-pastoral/)

Two planets keep and lose small moons under real gravity.

Leapfrog n-body integration, drawn as an engraved astronomer's chart.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/orbital-pastoral/). Add `?t=<seconds>` to render a single fixed frame.
