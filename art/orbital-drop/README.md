# Orbital drop

[![preview](preview.webp)](https://aalquwayfili.com/art/orbital-drop/)

A pod streaks toward a low-poly world.

Canvas 2D, a low-poly terrain in perspective.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/orbital-drop/). Add `?t=<seconds>` to render a single fixed frame.
