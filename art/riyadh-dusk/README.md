# Riyadh at dusk

[![preview](preview.webp)](https://aalquwayfili.com/art/riyadh-dusk/)

A hazy skyline as the sun goes down.

Canvas 2D silhouettes in blurred layers.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/riyadh-dusk/). Add `?t=<seconds>` to render a single fixed frame.
