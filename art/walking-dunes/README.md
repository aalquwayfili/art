# Walking Dunes

[![preview](preview.webp)](https://aalquwayfili.com/art/walking-dunes/)

A crescent dune grows out of a sand-slab simulation and walks downwind, burying a mud-brick watchtower.

Werner-style sand-slab model on a heightmap, drawn at 320×180 with ordered dither and cel lighting.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/walking-dunes/). Add `?t=<seconds>` to render a single fixed frame.
