# The Muqarnas Clock

[![preview](preview.webp)](https://aalquwayfili.com/art/muqarnas-clock/)

A red pencil hand sweeps the plan of a muqarnas dome, lighting one niche at a time until the crown star glows.

An architect's ink drawing; the 145 cells are built from exact Islamic geometry.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/muqarnas-clock/). Add `?t=<seconds>` to render a single fixed frame.
