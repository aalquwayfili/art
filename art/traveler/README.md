# The Traveler

[![preview](preview.webp)](https://aalquwayfili.com/art/traveler/)

A white sphere over a planet's edge, with rings of glyphs orbiting.

Canvas 2D.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/traveler/). Add `?t=<seconds>` to render a single fixed frame.
