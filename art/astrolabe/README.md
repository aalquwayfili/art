# Astrolabe

[![preview](preview.webp)](https://aalquwayfili.com/art/astrolabe/)

Rings and ticks turning around an eight-point star, in ink and gold.

Canvas 2D.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/astrolabe/). Add `?t=<seconds>` to render a single fixed frame.
