# Liquid light

[![preview](preview.webp)](https://aalquwayfili.com/art/liquid-light/)

Glassy blobs merging and splitting.

Metaballs on a small field, upscaled and blurred.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/liquid-light/). Add `?t=<seconds>` to render a single fixed frame.
