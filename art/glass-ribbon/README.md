# Glass ribbon

[![preview](preview.webp)](https://aalquwayfili.com/art/glass-ribbon/)

A glass ribbon full of orange sparks drifting through blue space.

Canvas 2D particles with layered blur for depth of field.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/glass-ribbon/). Add `?t=<seconds>` to render a single fixed frame.
