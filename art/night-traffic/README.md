# Night Traffic

[![preview](preview.webp)](https://aalquwayfili.com/art/night-traffic/)

Queues build at red lights and spread backwards as waves while car 042 makes its way home.

Nagel–Schreckenberg traffic automaton on a signalised grid, drawn as a blueprint with a space-time diagram.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/night-traffic/). Add `?t=<seconds>` to render a single fixed frame.
