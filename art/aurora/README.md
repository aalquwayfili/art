# Aurora over dunes

[![preview](preview.webp)](https://aalquwayfili.com/art/aurora/)

Aurora over dark dunes.

Canvas 2D gradients in blurred layers.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/aurora/). Add `?t=<seconds>` to render a single fixed frame.
