# The Last Grain

[![preview](preview.webp)](https://aalquwayfili.com/art/last-grain/)

Ride the last grain of an hourglass down through the neck, then pull back to the desk.

A 1-bit dithered plate with one vermilion grain among thousands.

An `index.html`, the code in `main.js`, and the shaders in `background.frag`, `grain.frag`, `grain.vert`, `post.frag` and `quad.vert`; no libraries. [View it live](https://aalquwayfili.com/art/last-grain/). Add `?t=<seconds>` to render a single fixed frame.
