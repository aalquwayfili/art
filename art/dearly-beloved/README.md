# Dearly Beloved

[![preview](preview.webp)](https://aalquwayfili.com/art/dearly-beloved/)

Ridgelines rising and falling like a slow piano piece.

Canvas 2D ridgelines from noise.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/dearly-beloved/). Add `?t=<seconds>` to render a single fixed frame.
