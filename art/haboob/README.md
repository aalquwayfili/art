# Haboob

[![preview](preview.webp)](https://aalquwayfili.com/art/haboob/)

The dust took the whole city for a minute. It couldn't find the kite.

Three-ink risograph: separate masks, rotated halftone screens and misregistration; the storm's wind is a flow field.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/haboob/). Add `?t=<seconds>` to render a single fixed frame.
