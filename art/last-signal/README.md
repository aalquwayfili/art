# Last Signal

[![preview](preview.webp)](https://aalquwayfili.com/art/last-signal/)

A dish on a Riyadh roof catches one song from 1987; the needle stitches it, then it unravels into static.

Embroidery in a hoop: satin stitch, dithered cross-stitch sky, French-knot stars.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/last-signal/). Add `?t=<seconds>` to render a single fixed frame.
