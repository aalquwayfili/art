# Heat Island

[![preview](preview.webp)](https://aalquwayfili.com/art/heat-island/)

The city makes its own weather: heat off the rooftops builds towering clouds that rain.

A small convection model with latent heat, drawn as flat cel-shaded anime clouds.

An `index.html` and the code in `main.js`; no libraries. [View it live](https://aalquwayfili.com/art/heat-island/). Add `?t=<seconds>` to render a single fixed frame.
